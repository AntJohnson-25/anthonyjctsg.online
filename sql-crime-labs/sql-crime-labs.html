        What you'll learn: a free SQL learning game
        
SQL Crime Labs is a free SQL game for beginners and analysts. Each case request is a real SQL practice problem: you write the query, SQLite runs it in your browser, and the rows it returns walk onto the evidence table as a 3D hologram. Three tries per case, a clue before the last one, and a worked solution with an explanation after.

        
    
          
  • Rookie (9 cases): SELECT, WHERE, AND/OR, IN, LIKE, ORDER BY, LIMIT, DISTINCT and first aggregates.
    • 
          
  • Semi-Pro (9 cases): GROUP BY, HAVING, INNER and LEFT JOIN, NULLs, subqueries, CASE and dates.
    • 
          
  • Pro (8 cases): CTEs, window functions, self-joins, a recursive query and set operations.
    •
